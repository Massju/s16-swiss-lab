# S16 瑞士轮 LAB

面向 **2026 英雄联盟全球总决赛（S16）瑞士轮** 的抽签与赛果模拟网站。纯静态 HTML / CSS / JavaScript，无构建步骤、无外部依赖。

## 在线地址

**https://massju.github.io/s16-swiss-lab/**

GitHub 仓库：https://github.com/Massju/s16-swiss-lab

打开 `index.html` 即可使用；也可以直接双击单文件版 **`s16-swiss-lab.html`**（CSS / JS / 图标全部内联，便于单独分享）。

在当前目录启动静态服务器：

```bash
python3 -m http.server 4173
# http://127.0.0.1:4173/
```

## 能做什么

- **抽签台**：按官方种子池抽首轮签；逐轮按战绩配对；点击队伍判定胜者，点击另一队即可改判；也可以让实力模型结算本轮。
- **手动排签**：瑞士轮与八强均可手动配对。瑞士轮校验种子池 / 同赛区 / 同战绩 / 不重赛；八强校验 3-0 必对 3-2 的保护规则。支持合法对位高亮、自动补齐、逐对删除。
- **更简洁的主界面**：棋盘、轮次条、操作台三段式；战绩默认折叠；去掉说明段落、卡片标签和重复小字。
- **官方队伍图标**：16 支队伍均使用 LoL Esports 官方队伍 logo，不带外围图标框；单文件版会把 logo 一并内联。
- **精确抽签概率**：不做随机模拟，直接穷举当前状态下所有合法签表。首轮固定为 **154 种**（1 号池 vs 4 号池 11 种 × 2 号池 vs 3 号池 14 种），并给出每支队伍的每个潜在对手概率。
- **全部首轮签表**：在“概率实验室”中浏览 / 导出全部 154 种合法首轮签。
- **蒙特卡洛全赛会模拟**：可模拟 5K / 20K / 50K / 100K 届赛会，输出八强、四强、决赛、冠军概率，3-0 概率、平均胜场、赛区汇总和常见八强组合。
- **完整淘汰赛**：瑞士轮结束后可按“3-0 对 3-2、其余随机”随机抽八强，也可以手动排八强；随后模拟或手动完成 BO5 单败淘汰赛。
- **实力值编辑**：默认 Elo 实力值可拖动调整，支持“全员五五开 / LCK 强势 / LPL 强势”预设。
- **本地保存与撤销**：赛程自动保存在浏览器 localStorage；支持撤销、重置、导出当前赛程 JSON。
- **改判保护**：改判已结束的比赛会先确认，并清除该轮之后的抽签与赛果；淘汰赛改判同理。

## 实现的 S16 瑞士轮规则

| 项目 | 规则 |
| --- | --- |
| 参赛队 | 16 支 |
| 轮次 | 5 轮 |
| 晋级 / 淘汰 | 3 胜晋级八强，3 负淘汰 |
| 首轮抽签 | 1 号池 vs 4 号池，2 号池 vs 3 号池；同赛区规避 |
| 后续抽签 | 同战绩配对；允许同赛区；不允许重复对阵 |
| BO1 / BO3 | 涉及晋级或淘汰的比赛为 BO3，其余 BO1（R3 的 1-1 组为 BO1） |
| 八强 | 两支 3-0 队伍分别对阵 3-2 队伍，其余四队随机配对；BO5，不规避同赛区 |

首轮种子池：

- 1 号池：GEN、AL、TLAW、G2
- 2 号池：HLE、BLG、TSW、LOS
- 3 号池：T1、TES、LYON、MKOI
- 4 号池：DK、IG、CFO、KC（入围赛胜者）

默认载入 2026-10-19 公布的官方首轮签；也可以在控制台随机重抽首轮。

## 视觉方向

- 参考 LoL Esports 官方转播与 BP 界面：深海军蓝、金色强调、青绿数据色。
- 系统无衬线 + 等宽数字；标题克制，数据优先。
- 2px 直角化处理；主界面不再使用大圆角卡片，改用分割线与留白组织信息。
- 队伍图标直接使用官方 logo，不再套圆角矩形底板。

## 建模假设

- 每一种合法配对视为等概率签表。若官方现场采用“抽到非法再重抽”的流程，个别对位概率可能有细微差异。
- 比赛结果由 Elo 模型独立模拟：单局胜率 `1 / (1 + 10^((Rb-Ra)/400))`，再换算 BO3 / BO5 系列赛胜率。
- 默认实力值以官方种子作为初始先验，用 2026 公开比赛结果更新计算；不是手工排名。可以在“赛制与数据”页调整，并保存在浏览器本地。页面不展示数据来源、样本区间与更新时间。
- 不包含版本、选手状态、BP、选边等额外因素。
